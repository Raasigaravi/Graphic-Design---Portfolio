# Raasigaravi R — Independent Creative Portfolio

This is a plain HTML, CSS and JavaScript portfolio. It does not require React, Node.js, a build step, or Emergent credits.

## 1. Preview on your computer
1. Extract the ZIP file.
2. Open the `raasi-independent-portfolio` folder.
3. Double-click `index.html` to preview it in your browser.

## 2. Update your contact details
Your email, LinkedIn and GitHub links are set at the top of `script.js` (and in the contact cards in `index.html`). Edit them there if they ever change, then refresh the browser.

## 3. Update your photo and creative assets
The About section uses `images/potrait.png`. To replace it, add your photo to the `images` folder and update the image's `src` in `index.html`. Keep the path relative to `index.html` so the photo also works when the portfolio is published.

The Video section plays `videos/ai-video-01.mp4` and `videos/ai-video-02.mp4`, using `images/video-poster.jpg` as the thumbnail. Keep these files in their folders when moving or publishing the project. Replace the video files or update their paths in `index.html` to change the clips.

## 4. Publish on Netlify
1. Create/sign in to a Netlify account.
2. In the Netlify dashboard, choose **Add new site** / **Deploy manually** (wording may vary).
3. Drag the extracted project folder (the folder containing `index.html`, `styles.css`, and `script.js`) into the deploy area.
4. Netlify will provide a public website URL.
5. Test the live URL on desktop and mobile.

## Notes
- This is a fresh static recreation based on the supplied portfolio structure and visual direction. It is not a byte-for-byte export of the Emergent React project.
- The About portrait uses `images/potrait.png`; the Video section contains two AI-generated experiments.
- Flowstate is clearly labelled as a fictional, self-initiated concept campaign.
- Before publishing, verify your email, LinkedIn and GitHub links.
